# Changelog

All notable changes to Vibratto Metadata are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [Unreleased]

First version of Vibratto Metadata.

### Added

- Import of a YouTube Music artist's whole discography: albums, singles, EPs, tracks and credits.
- Related artists saved as profiles, with a suggestion to import the big ones.
- Audio download by YouTube Music video id, with tagging, ReplayGain and file organisation.
- Lyrics from LRCLIB and YouTube Music, stored as `.lrc` files.
- New-release watches, block list, folder import, track upload and library backup.
- Proxy management with rotation.
- English and Spanish.
